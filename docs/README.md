# Documentación de EstrategiaT

La documentación está separada por audiencia para evitar mezclar instrucciones operativas, decisiones comerciales y detalles técnicos.

## Comercial

- [Ficha comercial](comercial/ficha-comercial.md): resumen breve de la propuesta de valor.

## Guías de operación

- [Portal de proveedores](guias/portal-proveedores.md): uso del portal, peticiones, cotizaciones y seguimiento.

## Documentación técnica

- [Aplicación móvil](tecnico/aplicacion-movil.md): construcción y sincronización con Capacitor.

## Convenciones

- Los nombres de archivos usan minúsculas y guiones.
- Las migraciones conservan prefijo numérico para indicar su orden.
- `www/` es un resultado generado; los cambios se realizan en los archivos fuente.
- Las plantillas de documentos se agrupan dentro de `templates/` por módulo.
